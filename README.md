# LazyMate AI ✨

**Make boring tasks easier, one small step at a time.**

LazyMate AI is a simple productivity assistant built for the Hacktoberfest 2026 Week 3 “Slow and Steady” challenge.

## 💡 What it does
- Turns repetitive tasks into simple steps.
- Creates a short checklist.
- Suggests a time-saving shortcut.
- Helps users get started without feeling overwhelmed.

## 🧠 Open-source AI
LazyMate AI uses the open-weight Qwen 2.5 model through Ollama, running locally on your computer. This makes AI more accessible and helps keep task prompts on your own device.

## 🛠️ Built with
- HTML, CSS, JavaScript
- Ollama
- Qwen 2.5 (1.5B)

## 🚀 How to run
1. Install Ollama and download `qwen2.5:1.5b`.
2. Start Ollama.
3. Open a terminal in the project folder.
4. Run `python -m http.server 8002`.
5. Visit `http://localhost:8002`.

## 🌱 Why open innovation matters
Open models let more people experiment, learn, and build useful AI tools on their own computers without relying entirely on paid hosted AI services.
